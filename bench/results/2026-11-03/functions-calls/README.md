The independent [CPU 2 holdout](holdout-cpu2.json) used 31 paired engine-phase probes and 61 paired process launches. Wasmtime compile/instantiate was 33.758 → 31.739 ms, a paired 1.060× speedup (MAD 0.015); native first entry was 1.006× (MAD 0.126) and V8 first entry 1.025× (MAD 0.140), inconclusive. CPU 2 pins inherited engine workers. The separate [normal-pool holdout](holdout-default.json) had 61 process pairs: ordinary native host 1.039× (MAD 0.150), precompiled 0.943× (MAD 0.156), and V8 1.021× (MAD 0.159); variation prevents a clear process-speed claim. Process launches include startup; ordinary launches include compilation, while precompiled launches exclude preparation. First entry includes initialization and callbacks, and V8 includes lazy JIT. Warmed body timings use a different boundary.

The [all-site helper experiment](rejected-warmed.json) was rejected after Sieve regressed about 20% despite identical hot instructions. A shifted loop crossing a 64-byte cache line is a plausible cause, not proven; see the [diagnosis](sieve-diagnosis.json). A bootstrap timestamp bug caused Ninja to reuse a stale prototype before qualification; a regression test covers the fix and all timings used the correct frozen compilers.
