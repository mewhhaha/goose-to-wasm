Goose Examples

Goose examples in WebAssembly

All nine official graphics samples from the Goose programming language (aardappel/goose, 1838de45) are compiled unmodified to WebAssembly with goose-to-wasm (goosew v2026.4-3), using the drop-in stdlib-web standard library. There is no C compiler in the path and no edit to any Goose source file.

Compile with stdlib-web

goosew 31_mini_doom.goose --stdlib stdlib-web --target wasm-direct -O2 \
  --wasm-max-pages 32767 -o mini_doom.wasm

--stdlib stdlib-web keeps the same Goose module names and APIs but binds the native modules to browser APIs, and embed_shader packs each GLSL shader straight into the .wasm module.

ModuleIn the browser
gfx, embed_shader WebGL2 renderer, GLSL 450 to ES 3.00 transpiler, input, PNG screenshots, and a WebAssembly JSPI frame loop (while gfx::frame())
ui Immediate-mode widgets rendered on Canvas 2D, with embedded TTF fonts loaded through FontFace
physics Dependency-free 3D rigid-body box solver in JavaScript
audio, os, slice_pool Web Audio mixer, virtual filesystem (MemoryFS, LocalStorageFS, OPFSAdapter), and a pure-Goose B+ span tree

Run in the browser

import { loadGoose } from "./host/web/index.js";

const canvas = document.querySelector("canvas");
const loaded = await loadGoose("./gfx_cube.wasm", {
  canvas,
  asyncFrame: true,
});
await loaded.runAsync();

runGoose(...) runs non-interactive software programs synchronously, start to finish, in any browser. Interactive while gfx::frame() loops hand each frame back to the browser through WebAssembly JSPI, available in Chrome 137 and later, or in Firefox and Safari with JSPI enabled.
