# Functions performance

The direct backend removes duplicate snapshots in eligible tail-only callback forwarding. It requires identity forwarding without remapping, non-owning fixed closed immutable parameters, scalar or void results, and a terminal body independent of the bypassed bindings. Arguments are evaluated left to right, with their first record snapshots constructed in the terminal bindings; borrowing is unchanged.

Functions shrank from 45,923 to 42,296 bytes (7.9%), and static `memory.copy` instructions fell from 427 to 317, mostly in cold sort-pivot paths. All non-code payload is identical. The baseline already includes the [earlier local pass](../bench/results/2026-11-03/functions/README.md); its measurements are a separate cohort.

In a 31-pair CPU 2 diagnostic holdout, native Wasmtime compile and instantiate fell from 35.311 to 32.881 ms, a paired 1.075× speedup (MAD 0.008). First entry was 0.972× (MAD 0.043), suggesting a possible small slowdown within noise. V8 first entry was 1.014× (MAD 0.058), also inconclusive. First entry includes initialization and callbacks; V8 also includes lazy JIT. CPU 2 pins inherited engine workers and is not the normal-pool process boundary.

The independent 61-pair normal-pool process holdout was noisy: paired ordinary native-host speedup was 1.027× (MAD 0.297), precompiled 1.035× (MAD 0.143), and V8 1.096× (MAD 0.324). The fresh 15-sample cohort measured Functions at 19.306 ms ordinary (MAD 1.020), 1.777 ms precompiled (MAD 0.558), and 0.899 ms native C (MAD 0.126); precompiled excludes preparation. C-to-Wasm took 28.910 ms ordinary (MAD 1.552) and 1.678 ms precompiled (MAD 0.336). These figures include process startup and are not paired with the prior cohort.

Nine paired warmed rounds across ten workloads gave geometric mean baseline/current speedups of 0.996× on Wasmtime and 1.000× on V8; all ten module bytes were unchanged, so these are noise controls. The compiler passed 67 focused gates, 9,573 differential executions and 11,484 host replays. A shared EnsureMemory slow path remains an unmeasured proposal. [Measurements, identities and retained experiments](../bench/results/2026-11-03/functions-forwarding/README.md) record the boundaries and results.
