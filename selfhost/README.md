# Goose in Goose

The compiler is written in Goose: source loading, parsing, checking, specialization, optimization, native C and direct Wasm emission, and the command-line driver. The [IR contract](IR.md) describes the stage interfaces.

## Bootstrap

From the repository root, with Python 3 and a native C compiler (Clang by default):

```sh
source build/performance-env.sh
python scripts/bootstrap.py --verify
```

The checked-in seed is C generated by the Goose compiler. Bootstrap builds the seed, uses it to compile the current Goose compiler to C, and builds that compiler. Verification generates two further C generations and checks that their output is identical. The installed compiler and standard library are in `build/bin`; `build/bootstrap/report.json` records inputs and commands. Use `--cc` to select a C compiler.

## Contracts

```sh
python tests/conformance.py --compiler build/bin/goose \
  --output-dir build/conformance --levels 0 2
```

Use a fresh output directory. The suite checks frozen sources, outputs, exit statuses and failure phases without a reference compiler or an expected-output update mode. The report records failures and input hashes. See the [guide](../docs/GUIDE.md) for build and execution commands.
