The full suite passed 7,771/7,871 rows, retaining snapshot 56's 100 gaps; all 84 new rows passed. The curated corpus passed 3,370/3,370 Wasm checks per engine and 1,410/1,410 native controls. Existing rows and expectations were preserved. Fifty independently authored checks also passed on the canonical compiler. No C++ compiler was used for bootstrap or conformance.

The two changes are conservative: omit forwarding only for emitted modules proven to use scalar and fixed scalar-array values, then use typed Wasm locals for eligible scalar parameters and simple declarations. Captured variables, compound values, references and complex bindings retain memory storage. Frame offsets, reservations, effect mailboxes and debug arithmetic checks stay intact. This preserves the activation-limit boundary while removing redundant scalar memory traffic. The native backend is unchanged; functions C emission is byte-identical at O0 and O2.

The [reproduction capsule](reproduction.tar.gz) includes the parent and candidate sources, parent/current C seeds, standard library, native headers, standalone bootstrap and contract runners, frozen fixtures and expectations, exact raw reports, source-review guards, patches and smaller exploratory pilots. The [inventory](reproduction-manifest.json) and [verification receipt](capsule-verification.json) record extraction and hash checks; all 3,644 non-binary pinned inputs are represented. The source-only capsule explicitly excludes five prebuilt executable inputs. Executable hashes remain recorded, and compiler executables can be rebuilt with the supplied C-only bootstrap.

After extracting into a fresh directory, `python3 REPRODUCE.py --help` lists the verification, composition, bootstrap and conformance commands. Verification checks archived hashes; composition reapplies only the combined patch to the frozen parent and checks every resulting source. Bootstrap starts with the frozen C seed. Full conformance retains the same 100 known gaps rather than treating them as passes. Raw reports retain the original absolute workspace paths; the reproduction helper uses portable extracted paths.

Rejected source drafts and experiments are retained separately from admitted guards. A draft relying on a view after shrink was invalid under the language contract; varint arrays were not indexable. Neither became an expected successful runtime case. The initial resolver-only and combined candidates, source seals, four-pair smaller pilots, and independent reviews remain in the capsule. Those pilots are exploratory; the dated benchmark report supplies the final measurements. The scalar proof deliberately leaves compound programs on the old path, and the slot descriptor adds compiler-side table storage. Frame reservations remain unchanged, so this change does not remove frame setup or increase the activation limit.

Canonical qualification diagnostics were 30.27 s to compile the parent C seed, 48.65 s to emit the compiler's C, 30.11 s to compile that C, and 47.79 s for the verification emission. These single observations were collected during qualification under host load, not as a controlled compiler-construction comparison. The compiler-speed chart separately measures repeated source-to-Wasm and source-to-C compilation of eleven programs.
